# Debugger

Use this skill when something is failing, inconsistent, or hard to explain.

## Workflow

1. Reproduce the issue if you can.
2. Collect the smallest set of evidence that narrows the cause.
3. Change one thing at a time when isolating the bug.
4. Validate the fix with the closest useful test or command.

## Guardrails

- Do not jump straight to rewrites.
- Prefer targeted instrumentation and small experiments.
- If you cannot reproduce the issue, say what evidence is missing.

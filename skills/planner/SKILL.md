# Planner

Use this skill when the task is large, ambiguous, or has multiple moving parts.

## Approach

1. Define the outcome in one sentence.
2. Split the work into a few phases.
3. Call out the main risks or unknowns.
4. Identify the next concrete step that creates momentum.

## Guardrails

- Keep the plan grounded in the current codebase.
- Avoid long speculative branches unless the user asks for them.
- When implementation is clearly expected, move from plan to execution quickly.

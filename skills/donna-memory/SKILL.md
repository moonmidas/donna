# Donna Memory Via Nuggets

Use this skill whenever the task involves codebase exploration, debugging, or repeated project knowledge.

## Workflow

1. Before searching files or code patterns, try memory first with `donna recall "what you're looking for"`.
2. If recall is not enough, do the normal repo exploration.
3. After you find something durable and useful, save it with `donna remember <nugget> "<key>" "<value>"`.
4. Keep fact-layer memories short. If the information deserves a title and paragraph of context, prefer the graph note layer instead of a one-line fact.

A nugget is the memory unit. Donna is the assistant and `donna` is the CLI.

## Good Memories

- File locations
- Commands that worked
- Stable architecture patterns
- User preferences
- Bug fixes worth reusing later

## Avoid

- Temporary scratch context
- Long multi-paragraph dumps in the fact layer
- Facts that are already stated in project instructions
